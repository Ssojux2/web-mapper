# Web Mapper

브라우저에서 영상을 실물에 프로젝션 맵핑하는 프로그램입니다. MadMapper의 비디오 맵핑 기능 중 핵심만 먼저 구현했습니다.

## 바로 쓰기

설치할 것이 없습니다. Chrome 또는 Edge(맥·윈도우)에서 아래 주소를 엽니다.

**https://ssojux2.github.io/web-mapper/**

앱처럼 쓰려면 편집기 위쪽의 `⤓ 앱 설치` 버튼(또는 주소창 오른쪽의 설치 아이콘)을 누릅니다. 바탕화면·Dock에 아이콘이 생기고 별도 창으로 열립니다. 한 번 연 뒤에는 인터넷이 없는 공연장에서도 실행됩니다. 새 버전이 배포되면 다음에 열 때 자동으로 반영됩니다.

Chrome에서 유튜브 같은 웹 영상을 캡처해 쓰면 출력 창에 Chrome의 공유 표시가 남을 수 있습니다. 출력에 영상만 내보내야 하면 [데스크톱 앱](#데스크톱-앱-macoswindows)을 쓰세요.

작업한 프로젝트와 미디어는 그 컴퓨터의 브라우저에만 저장됩니다. 다른 컴퓨터로 옮기려면 `저장`으로 `.mapper.json` 파일을 내보내고, 미디어 파일과 함께 가져가세요.

## 사용 순서

1. **Media** 탭에서 영상이나 이미지를 추가합니다. 파일을 패널에 끌어다 놓아도 됩니다.
2. **Surfaces** 탭에서 `+ Quad`로 서피스를 만들고, 미디어를 Output 뷰의 서피스 위에 끌어다 놓습니다.
3. **Output** 탭에서 해상도를 프로젝터에 맞추고, `화면 목록`으로 프로젝터를 고른 뒤 `출력 창 열기`를 누릅니다.
4. 출력 창을 클릭하면 전체화면이 됩니다(F 키로 전환).
5. Output 뷰에서 코너 핸들을 실물 모서리에 맞춥니다. Input 뷰에서는 영상의 어느 부분을 쓸지 고릅니다.

### 한 서피스에 여러 영상 겹치기 (레이어)

서피스마다 레이어를 여러 장 쌓을 수 있습니다. 인스펙터의 **레이어** 목록에서 위에 있는 레이어가 앞에 그려집니다.

- `+ 레이어`로 추가하고 ▲▼로 순서를 바꿉니다. Media 탭의 `레이어로 겹치기`나, 미디어를 Shift를 누른 채 서피스에 놓아도 새 레이어로 들어갑니다(그냥 놓으면 선택한 레이어의 미디어가 바뀝니다).
- 레이어마다 미디어, 불투명도, 블렌드(보통·더하기·스크린·곱하기)를 정합니다. 맨 아래 레이어는 블렌드 없이 깔립니다.
- Input 뷰는 선택한 레이어의 미디어를 보여 주고, 레이어마다 쓸 영역을 따로 자릅니다.
- 코너 핀, 메시 워프, 마스크, 서피스 불투명도는 레이어를 합친 결과 전체에 적용됩니다.

### 유튜브 등 웹 영상 쓰기 (창/화면 캡처)

**Media** 탭의 `+ 창/화면 캡처`로 다른 창이나 화면을 실시간 소스로 씁니다.

1. 유튜브 영상을 **별도 창**으로 엽니다(탭을 끌어내 새 창으로 만들거나, 영상 위에서 F를 눌러 플레이어를 전체화면으로).
2. `+ 창/화면 캡처`를 누르고 Chrome 선택 창의 **“창”**에서 그 유튜브 창을 고릅니다.
3. 주소창이나 창 테두리가 같이 찍히면 Input 뷰에서 영상 부분만 잘라 냅니다.
4. 화면 아래쪽에 뜨는 Chrome의 공유 알림은 “숨기기”로 내립니다.

**탭을 고르면 안 되는 이유**: 탭을 공유하면 Chrome이 모든 창(출력 창 포함)의 위쪽에 “Sharing … / Stop sharing” 바를 붙입니다. 이 바는 전체화면에서도 사라지지 않고 웹 페이지가 지울 수 없습니다. 탭을 골랐다면 인스펙터의 `창으로 다시 선택`을 누르세요.

- 메시 워프, 마스크, 원근 보정이 그대로 적용됩니다.
- 캡처하는 창을 최소화하면 화면이 멈출 수 있습니다. 다른 창 뒤에 두는 것은 괜찮습니다.
- 출력 창은 편집기의 `출력 창 열기`로 열어야 캡처가 보입니다(편집기의 스트림을 그대로 빌려 씁니다).
- 실시간 소스라 반복·탐색이 없고, 새로 고치면 `다시 선택`으로 다시 골라야 합니다. 브라우저의 “공유 중지”를 누르거나 미디어를 지우면 캡처가 끝납니다.
- 화질은 캡처한 탭의 표시 크기를 따릅니다. 남의 영상을 공개 장소에 투사할 때는 이용 허락을 확인하세요.

### 곡면·복잡한 물체 (동상 등)

Output 뷰 위쪽의 편집 모드로 전환합니다.

- **메시 (W)**: 인스펙터나 안내 줄에서 메시를 켠 뒤 격자 점을 끌어 곡면에 맞춥니다. 코너 핀을 움직여도 휜 모양이 따라갑니다. 격자 수(최대 32×32), 부드러운 곡선/직선을 고를 수 있습니다.
- **마스크 (M)**: 빈 곳을 클릭해 점을 찍고, 첫 점을 누르거나 Enter로 닫습니다. 기본은 안쪽만 보이고, “가림”으로 바꾸면 안쪽을 가립니다. 페더로 가장자리를 흐리게 합니다. Shift+클릭으로 변에 점을 추가합니다.
- **참조 (R)**: Output 탭에서 프로젝터 자리에서 찍은 사진을 불러와 네 코너로 맞춥니다. 편집기에만 보이고 출력 창에는 나가지 않습니다. 테스트 패턴을 켠 채로 사진을 찍으면 정렬하기 쉽습니다.

작업 내용은 자동 저장됩니다. `저장`은 `.mapper.json` 파일로 내보냅니다.

## 데스크톱 앱 (macOS·Windows)

웹 버전과 같은 편집기를 설치형 앱으로 씁니다. 다른 점은 이렇습니다.

- **출력에 영상만 나옵니다.** 창·화면을 캡처해도 공유 바나 알림이 출력 창에 생기지 않습니다(Chrome에서 탭을 공유하면 생기는 바가 없습니다).
- 출력 창이 고른 화면(프로젝터)에 테두리 없이 바로 전체화면으로 열립니다. 화면 목록은 앱을 열면 자동으로 채워집니다.
- 캡처할 창·화면은 앱 안의 선택 창에서 썸네일을 보고 고릅니다.

### 내려받기

[GitHub Releases](https://github.com/Ssojux2/web-mapper/releases)에서 받습니다(출시 전에는 저장소의 Actions → *Desktop app* 실행 결과의 Artifacts).

| 운영체제 | 파일 |
| --- | --- |
| macOS (Apple Silicon: M1 이후) | `Web Mapper-x.y.z-mac-arm64.dmg` |
| macOS (Intel) | `Web Mapper-x.y.z-mac-x64.dmg` |
| Windows 10·11 (64비트) | `Web Mapper-x.y.z-win-x64-setup.exe` |

### 처음 열 때 (서명 전이라 뜨는 경고)

아직 코드 서명을 하지 않아 처음 한 번 경고가 뜹니다.

- **macOS 15 이후**: dmg에서 앱을 응용 프로그램 폴더로 끌어 놓고 엽니다. “열 수 없음” 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **“그래도 열기”**를 누릅니다.
- **macOS 14 이하**: 앱을 Control+클릭(우클릭) → **열기** → 다시 **열기**.
- **Windows**: “Windows의 PC 보호” 창에서 **추가 정보 → 실행**을 누릅니다. 설치 위치는 바꿀 수 있고, 관리자 권한은 필요 없습니다.

### macOS 화면 기록 권한

창·화면 캡처를 처음 쓸 때 macOS가 권한을 묻습니다. 거부했거나 목록이 비어 있으면 캡처 선택 창의 `시스템 설정 열기`를 눌러 **화면 및 시스템 오디오 기록**에서 Web Mapper를 켜고 앱을 다시 시작합니다.

### 웹 버전과의 차이

- 저장 공간이 따로라 웹에서 하던 작업은 자동으로 넘어오지 않습니다. 웹에서 `저장`한 `.mapper.json`을 앱에서 `열기`로 불러오세요.
- 설치 버튼과 오프라인 캐시는 앱에 필요 없어 꺼져 있습니다. 새 버전은 새 설치 파일로 덮어 설치합니다.

## 브라우저 지원

- **Chrome·Edge**: 모든 기능. 출력 창이 고른 화면에 자동으로 열리고, 미디어 파일은 다시 열 때 권한만 허용하면 재연결됩니다.
- **Safari·Firefox**: 맵핑과 출력은 됩니다. 출력 창은 직접 프로젝터 화면으로 옮겨야 합니다. 미디어는 브라우저 저장소에 복사본으로 보관합니다.
- 오디오는 아직 지원하지 않습니다(모든 영상이 음소거 재생).

## 구조

- `src/core`: 프로젝트 모델, 호모그래피·메시 워프 계산, 실행 취소 상태, 창 간 메시지
- `src/render`: WebGL2 렌더러(원근 보정 메시, 마스크 텍스처, 테스트 패턴, 영상 텍스처)
- `src/media`: 미디어 요소, 파일 선택, IndexedDB 보관
- `src/project`: JSON 저장·열기, 자동 저장
- `src/editor`: 편집기 UI(React)
- `src/output`: 출력 창, 화면 배치, 재생 동기화
- `src/desktop`: 데스크톱 앱과 화면 코드 사이의 API 타입(`window.mapperDesktop`)
- `electron`: 데스크톱 앱의 메인 프로세스(app:// 스킴, 출력 창, 캡처, 스모크 테스트)와 preload

## 개발

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 단위 테스트
npm run lint
npm run build
```

`main`에 push하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 배포합니다(`.github/workflows/deploy.yml`).

데스크톱 앱:

```bash
npm run app:dev     # Vite 개발 서버 + Electron
npm run dist:mac    # release/에 dmg(arm64·x64)
npm run dist:win    # release/에 설치 파일(x64), Windows에서 실행
npm run smoke       # 빌드된 앱을 --smoke-test로 실행해 주요 기능을 자동 점검
```

`.github/workflows/desktop.yml`은 macOS·Windows에서 설치 파일을 만들고, 실제로 설치한 앱을 `--smoke-test`로 실행해 점검합니다. 결과물은 Artifacts로 올라가고, `v*` 태그를 push하면 초안 릴리스가 만들어집니다(공개는 직접 합니다).
